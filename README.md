# royal-feast-restaurant-demo

A colourful, animated, responsive demo website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Publish
Create a GitHub repository named `royal-feast-restaurant-demo`, upload `index.html`, then enable GitHub Pages in **Settings → Pages**.

## Notes
- Menu prices, phone numbers, address, and contact email are demo content; replace before real use.
- Photos load from Unsplash, so an internet connection is needed for those images.
- Contact/reservation buttons open an email draft; they do not submit to a backend.
